NSGo Media 是面向 [NSGo](https://github.com/nsgo-dev/nsgo) 应用的视频播放器内核。它打开媒体源，用 FFmpeg 解码，同步声音和画面，播放声音并把画面绘制到视图中。所有控件都由应用自己实现，并通过 Go API 驱动内核。这部分文档写给开发这类应用的开发者；[NSGo Player](../) 就是本项目自己的应用。

:::note[开发中]
播放、声音、跳转、字幕和硬件解码已能在 macOS、Windows、Linux 和 iOS 上本地使用，但还没有发布任何版本。
:::

## 为什么需要内核

NSGo 的 `core.Video` 把媒体源交给各平台自带的播放器。各平台支持的格式不同（AVFoundation 打不开 MKV、AVI 和 FLV），应用也拿不到精确到帧的时钟、逐帧步进，以及可以随意在上面绘制的画面。NSGo Media 面向需要真正播放器的应用，比如媒体播放器、编辑器的预览和课程播放器。

## 内核做什么

- **媒体源**：本地文件和带应用所给请求头的 HTTP(S) 地址，任何内置 FFmpeg 能解码的容器和编码；还能把单独的音频源和画面一起播放，就像 DASH 提供的那样。
- **播放**：播放、暂停、停止，快速和精确跳转，向前或向后逐帧，0.25× 到 4× 保持音调的变速，循环和截图。
- **声音**：音量、静音和音轨，输出到系统默认设备；还能把 AC-3、E-AC-3、DTS、DTS-HD 和 TrueHD 直通给功放。
- **画面**：一个按 contain、cover 或 fill 绘制画面的视图，跟随流的旋转，应用的视图可以画在它上面。
- **字幕**：文本和位图字幕轨道以 cue 的形式交给应用绘制。
- **流**：HLS 和 DASH，点播和直播。
- **解码**：VideoToolbox、D3D11VA 和 VAAPI，失败时退回软件解码。
- **状态**：播放、暂停、缓冲、结束和出错状态，位置、缓冲范围和所选轨道，都是 NSGo 信号。

多个播放器可以同时播放，各有各的视图。

## 留给应用的

- 所有控件：播放按钮、进度条、菜单、手势和快捷键。
- 绘制字幕。内核交出字幕的文本和位图。
- 媒体库、播放列表、历史和设置。内核不持久化任何东西。

录制、转码、DRM、光盘镜像，以及 DLNA、AirPlay 这类接收端，都不在范围内。

## 平台

| 平台 | 目标 | 硬件解码 | 音频 |
| --- | --- | --- | --- |
| macOS 11 及以上 | arm64、x64 | VideoToolbox | CoreAudio |
| Windows 10 及以上 | x64 | D3D11VA | WASAPI |
| 带 glibc 2.34 和 libva 2 的 Linux | x64 | VAAPI | PulseAudio，PipeWire 的服务端同样支持 |
| iOS 15 及以上 | 真机、arm64 模拟器 | VideoToolbox | AudioQueue，不支持直通 |

内核还以 NSGo 支持的 tvOS、Android、Web 和鸿蒙为目标。这些都还是目标，内核目前还不能在上面播放。
