NSGo Player 是本项目用自己的内核做的桌面应用，位于存储库的 `app/` 文件夹。它完整展示了基于 NSGo Media 的应用是什么样子：在 `player.View` 周围有自己的播放控件、字幕、全屏、快捷键和续播。

它的页面画的是插件给出的内容，应用本身不认识任何网站。内置的 **本地文件** 插件播放你文件夹里的视频，其他来源都来自你添加的插件。

:::note[开发中]
NSGo Player 可以在 macOS、Windows 和 Linux 上从检出目录运行，还没有发布版本。
:::

## 运行

NSGo Player 是独立的 Go 模块，这样内核不会依赖只有应用才用的东西。在检出目录里：

```sh
cd app
go tool nsgo dev
```

和任何基于内核的应用一样，播放需要 FFmpeg 库，见 [FFmpeg 库](../ffmpeg/)。

## 本地文件

本地文件插件在首页列出你的视频文件夹，可以打开子文件夹、按名字搜索，也能播放粘贴的路径。和视频同名的字幕文件（如 `Movie.srt`、`Movie.zh-CN.ass`）会一起加载。

文件夹是它的设置项：打开 **设置**，在 **本地文件** 下的 **视频文件夹** 里填写，多个用 `;` 分隔。不填时列出系统的“影片”或“视频”文件夹。

侧栏的 **打开** 页面仍然可以打开任意单个文件或网址。

## 插件

在 **设置 → 插件** 里可以：

- 从文件夹或 zip 安装插件，插件会复制进应用；
- 从路径使用插件：在 **从路径使用** 里填插件文件夹的路径，应用每次启动都从原处读取，适合正在编写的插件；
- 开关每个插件、修改它的设置，或连同数据删除它。删除从路径使用的插件时，文件夹会保留。

添加插件之前，应用会列出它能连接的主机，请你确认。想自己写一个，见 [编写插件](../plugins/)。
