NSGo Player 是本项目的桌面视频播放器，支持 macOS、Windows 和 Linux。它播放你文件夹里的视频，其他来源都来自你添加的插件。应用本身不认识任何网站：它的页面画的是插件给出的内容。

:::note[开发中]
NSGo Player 可以从存储库的检出目录运行，还没有发布版本。
:::

## 运行

在 macOS、Windows 或 Linux 的检出目录里，装好 Go 后：

```sh
cd app
go tool nsgo dev
```

它会下载播放需要的 FFmpeg 库并放在应用旁边，它们从哪里加载见 [FFmpeg 库](core/ffmpeg/#加载位置)。Linux 上还需要 GTK 4、libva 和 PulseAudio 的客户端库（或 PipeWire 的 PulseAudio 服务），桌面发行版都会装好。

## 安装

在 `app/` 里运行 `go tool nsgo build`，会在 `app/dist/releases` 里生成各个桌面系统的安装包，都带着 FFmpeg 库：

| 系统 | 安装包 | 安装方法 |
| --- | --- | --- |
| macOS | `nsgo-player-…-macos-arm64.dmg` 或 `…-macos-x64.dmg` | 打开后把 NSGo Player 拖进“应用程序” |
| Windows | `nsgo-player-…-windows-x64-setup.exe` | 运行它；生成它需要 NSIS 的 `makensis` |
| Debian、Ubuntu | `nsgo-player-…-linux-x64.deb` | `sudo apt install ./nsgo-player-…-linux-x64.deb` |
| Arch | `nsgo-player-…-linux-x64.pkg.tar.gz` | `sudo pacman -U nsgo-player-…-linux-x64.pkg.tar.gz` |
| 任意 Linux | `nsgo-player-…-linux-x64.AppImage` | 加上可执行权限后运行 |

用 `-target` 只生成一个系统的，如 `go tool nsgo build -target linux_x64`。页面和下面的快捷键在各个系统上都一样。

## 播放视频

工具栏的 **打开** 页面可以打开你选的文件或粘贴的网址，把文件拖到窗口任意位置也能播放。视频在一个单独的无边框窗口里播放，默认 960×540，拖动画面就能移动窗口。鼠标停在窗口里时才显示顶部栏和控制条，鼠标离开窗口或静止 1.5 秒后，它们连同鼠标指针一起淡出：顶部是关闭、来源和标题，以及置顶；底部是播放和暂停、带缓冲范围的进度线、音量和静音、已播时间和总长（点一下改为显示剩余时间）、速度、字幕和音轨合在一个菜单里、插件提供时的分P、下一P和画质，以及全屏。置顶后窗口保持在其他窗口上方，缩小到 560×315，控制条只留少数按钮。视频页会提供从上次停下的地方继续播放那一P，或从头播放；播完后自动播放下一P。

插件可以提供视频的弹幕：播放时从画面上滚过，或固定在画面顶部、底部的评论。**DM** 按钮开关弹幕，旁边的箭头打开弹幕设置：显示哪些类型、不透明度、占画面多大区域、字号和速度。

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放或暂停 |
| ← 和 → | 后退或前进 5 秒 |
| ↑ 和 ↓ | 调高或调低音量 |
| F | 进入或退出全屏 |
| D | 显示或隐藏弹幕 |
| P | 置顶播放窗口，或取消置顶 |
| Esc | 关闭菜单、退出全屏，然后关闭播放页 |

## 本地文件

内置的 **本地文件** 插件在首页列出你的视频文件夹，可以打开子文件夹、按名字搜索，也能播放粘贴的路径。和视频同名的字幕文件（如 `Movie.srt`、`Movie.zh-CN.ass`）会一起加载。

文件夹是它的设置项：打开 **设置**，在插件列表里点 **本地文件**，在 **视频文件夹** 里填写，多个用 `;` 分隔。不填时列出系统的“影片”或“视频”文件夹。

## 插件

工具栏的 **首页**、**关注** 和 **发现** 把所有启用插件的视频合在一起显示，每张卡片用插件的图标标出来源；上方的 **全部来源** 显示全部，点某个插件的名字只看它的视频。**首页** 最前面是你看到一半的视频，**发现** 显示每个插件自己的第一个页面，只看一个插件时还能切到它的其他页面；搜索框或 ⌘K（Ctrl K）同时搜索所有插件。**关注** 按状态列出能记录关注的插件账号关注的剧集，标签上标出有新剧集的部数；剧集页可以关注、更改状态或取消关注，并播放上次看完的下一集。插件账号在设置里它的页面登录，或在页面提示时登录。**设置 → 插件** 列出所有插件和它们的开关，**添加插件** 可以：

- **从 GitHub…**：安装一个仓库最新 Release 里的插件 zip，输入 `owner/repo` 或粘贴仓库网址即可。仓库不存在、没有 Release，或最新 Release 里没有插件 zip 时，对话框会说明是哪种情况；
- **从文件夹安装…** 或 **从 zip 安装…**：把插件复制进应用；
- **从路径使用…**：在原处使用你选的文件夹，应用每次启动都从那里读取，适合正在编写的插件。

在列表里点一个插件会打开它的页面：开关、账号、设置、它能连接的主机，以及 **删除插件…**，会连同数据删除它。删除从路径使用的插件时，文件夹会保留。应用加载不了的插件（比如需要更新版本的应用）会留在列表里并说明原因，直到你删除它。

应用在启动时和之后每六小时检查一次从 GitHub 安装的插件的仓库有没有更新的 Release（不算预发布版），**插件** 旁边的刷新按钮可以立刻检查。有新版本时，插件那一行和它的页面会显示 **更新到 …**，**设置** 上也会显示红点。更新时会显示 Release 的说明，新增的主机需要你确认，插件的设置、数据和登录都会保留；需要更新版本应用的 Release 会被拒绝。

添加插件之前，应用会列出它能连接的主机，请你确认。插件只能访问这些主机，碰不到你的文件。想自己写一个，见 [编写插件](plugins/)。

## 语言

应用支持英文和简体中文，默认跟随系统，也可以在 **设置 → 语言** 里选择。插件自己的文字也随之切换。

## 使用统计

应用会匿名统计使用情况：显示的是哪类页面（不含插件或视频本身）、窗口大小、系统和语言，以及一个随机的安装 ID。可以在 **设置 → 发送使用统计** 里关闭。
