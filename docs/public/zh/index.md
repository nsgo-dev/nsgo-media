NSGo Player 是本项目的桌面视频播放器，支持 macOS、Windows 和 Linux。它播放你文件夹里的视频，其他来源都来自你添加的插件。应用本身不认识任何网站：它的页面画的是插件给出的内容。

:::note[开发中]
NSGo Player 可以从存储库的检出目录运行，还没有发布版本。
:::

## 运行

在检出目录里，装好 Go 和 NSGo 的工具后：

```sh
cd app
go tool nsgo dev
```

播放需要 FFmpeg 库，它们从哪里加载见 [FFmpeg 库](core/ffmpeg/#加载位置)。

## 播放视频

侧栏的 **打开** 页面可以打开你选的文件或粘贴的网址，把文件拖到窗口任意位置也能播放。播放页铺满整个窗口，控制条浮在画面上，播放时鼠标静止三秒后隐藏：播放和暂停、带缓冲范围的进度条、音量和静音、速度、字幕和音轨合在一个菜单里、插件提供时的分P、下一P和画质，以及全屏。视频页会提供从上次停下的地方继续播放那一P，或从头播放；播完后自动播放下一P。

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放或暂停 |
| ← 和 → | 后退或前进 5 秒 |
| ↑ 和 ↓ | 调高或调低音量 |
| F | 进入或退出全屏 |
| Esc | 关闭菜单、退出全屏，然后关闭播放页 |

## 本地文件

内置的 **本地文件** 插件在首页列出你的视频文件夹，可以打开子文件夹、按名字搜索，也能播放粘贴的路径。和视频同名的字幕文件（如 `Movie.srt`、`Movie.zh-CN.ass`）会一起加载。

文件夹是它的设置项：打开 **设置**，在插件列表里点 **本地文件**，在 **视频文件夹** 里填写，多个用 `;` 分隔。不填时列出系统的“影片”或“视频”文件夹。

## 插件

每个启用的插件在侧栏里都有自己的分区，包含它的首页、页面和搜索，有账号的插件还能在这里登录。**设置 → 插件** 列出所有插件和它们的开关，**添加插件** 可以：

- **从文件夹安装…** 或 **从 zip 安装…**：把插件复制进应用；
- **从路径使用…**：在原处使用你选的文件夹，应用每次启动都从那里读取，适合正在编写的插件。

在列表里点一个插件会打开它的页面：开关、账号、设置、它能连接的主机，以及 **删除插件…**，会连同数据删除它。删除从路径使用的插件时，文件夹会保留。应用加载不了的插件（比如需要更新版本的应用）会留在列表里并说明原因，直到你删除它。

添加插件之前，应用会列出它能连接的主机，请你确认。插件只能访问这些主机，碰不到你的文件。想自己写一个，见 [编写插件](plugins/)。

## 语言

应用支持英文和简体中文，默认跟随系统，也可以在 **设置 → 语言** 里选择。插件自己的文字也随之切换。

## 使用统计

应用会匿名统计使用情况：显示的是哪类页面（不含插件或视频本身）、窗口大小、系统和语言，以及一个随机的安装 ID。可以在 **设置 → 发送使用统计** 里关闭。
